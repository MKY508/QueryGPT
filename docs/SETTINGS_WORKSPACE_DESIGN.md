# 设置工作区

配置表单和分析服务目录分别以[表单合同](SETTINGS_FORMS.md)与[目录合同](MODEL_SERVICES.md)为准。桌面页面、导航、表单会话及明确页面链接的离开保护已归并；原生关闭仍需主进程和预加载配套交付，下文不表示已安装桌面成品已经验收。

## 所有权

| 模块 | 职责 |
|---|---|
| navigation.ts | 唯一栏目目录：身份、翻译键、页面归属、偏好分区与地址解析 |
| SettingsDirectory | 目录呈现、输入法确认后的搜索、真实链接 |
| useSettingsNavigation | URL 选择、已访问面板、共用偏好身份、每栏滚动与标题焦点 |
| SettingsCollection | 已加载目录的显式字段搜索、筛选、数量及 12 项分页 |
| useSettingsFormSession | 原始草稿、编辑身份、版本、关闭／替换及保存期间的同步锁 |
| SettingsEditor / SettingsNotice | 常驻桌面编辑面板与统一内联错误，不由窗口宽度切换成模态 |
| PreferencesSettings | 执行、外观、诊断共用草稿，按栏目提交差异 |
| SettingsExitGuard / exit-guard.ts | 聚合未保存状态，按当前版本决定明确丢弃，不保存配置 |
| 桌面桥与主进程关闭流程 | 原生菜单导航、关闭／退出与最终卸载事件 |

表单字段、默认值和校验只有[表单合同](SETTINGS_FORMS.md)这一处定义；服务检查状态与请求生命周期只有[目录合同](MODEL_SERVICES.md)这一处定义。

桌面布局、主题及圆角以 [桌面界面合同](DESKTOP_UI.md) 为准，旧手机行为不再适用。

## 栏目与目录

- 桌面固定目录。搜索只匹配现有栏目及描述，支持 NFKC、多词、中英文；不搜配置字段、不改变当前栏目、不调用接口。清除后保留搜索焦点。
- URL 决定栏目。链接更新 `tab`，保留无关参数及普通点击时的片段；重复当前栏目不加历史，连续操作以即时地址为准，修饰键保留浏览器行为。只接受目录中的五个身份；旧别名、退役及未知名称统一落到分析服务，不维护兼容映射。
- 按首次访问挂载模型、连接及共用偏好组件；离开栏目后以 `hidden`、`inert` 保留草稿。代码预热不触发配置查询。每栏保留本页滚动位置，明确切换与历史切换交接到可见标题。
- 连接列表搜索名称、类型、主机与数据库名，不序列化完整配置；按数据库类型筛选。名称是编辑按钮，当前编辑项高亮，默认项用文字标记，检查和删除只操作对应项。
- 搜索／筛选返回第一页；列表缩短后页码收敛，后来增长不跳回旧末页。翻页交接数量提示，清除交接搜索框。操作目录、检查或编辑会解除旧的删除确认。
- 列表搜索、分页和编辑草稿彼此独立。筛掉正在编辑的项不清除草稿；这些都是已加载列表的本页状态，不是服务器分页或跨刷新恢复。

## 草稿与编辑面板

- 比较原始填写值，不按裁剪后的请求负载判断修改；空格、布尔值和未完成数字都保留。未修改或改回原值可以直接关闭。
- 关闭有修改的表单、换对象、从编辑切到新增需明确放弃。再次选择同一对象或当前新增入口只返回表单。默认与 Escape 都继续编辑。
- 替换对象在确认时从当前目录解析；目标消失就保留草稿。确认绑定草稿版本，后续修改令旧决定失效；隐藏栏目取消待确认窗口，但不清除输入，也不在返回时复活旧决定。
- 保存同步去重并阻止关闭／替换；失败保留输入，成功只关闭匹配版本。资源层的保存后检查失败不能倒置为保存失败。不新增自动重试或自动提交。
- 目录与 420px 编辑面板始终并排。编辑器是普通 section，不注册视口监听、不建立原生模态；尺寸变化不重建输入。
- 子确认拥有焦点，底层编辑面板不处理关闭键。隐藏栏目保留输入节点但退出可操作范围。保存错误必须在编辑器内可见。
- 关闭后返回新增入口，继续编辑／换对象交接表单。确认模态拥有 Tab／Escape，桌面面板不锁住目录；组合输入的 Escape 不关闭。

## 偏好与离开

- 执行、外观与诊断共享草稿及写入锁。保存只提交当前栏目允许的差异，回执只更新该栏目字段并保留较新的未提交缓存值；不覆盖默认模型等其他模块的选择。成功只清理仍与该次提交一致的草稿，成功／失败提示归属提交栏目。隐藏组件暂停查询，不取消用户已发起的写入。主题／语言等即时选择不被放弃草稿回滚。
- 页面链接使用 Next Link `onNavigate` 与共享上下文，原生菜单页面导航复用同一决定；不覆盖路由内部、不插入历史哨兵、不引入导航依赖。
- 聚合可见与隐藏的模型、连接、偏好修改。留在设置保留所有内容；放弃并离开先明确清除当前版本草稿，再跳转，而非依赖卸载。决定同时绑定请求对象和草稿版本，修改、忙碌变化、卸载或新导航都会使旧决定失效。
- 保存中禁止放弃离开；保存完成或失败不自动跳转。已有表单放弃弹窗时，不叠第二个页面离开决定。弹窗只呈现目标和后果，不回显配置内容。
- 设置页独占 `beforeunload`，通过表单注册表覆盖隐藏草稿与未完成写入；表单不重复监听窗口事件。放弃回调完成后必须重新确认所有表单均无修改且不忙碌，不能仅凭回调已调用就批准离开。原生浏览器 Back／Forward 和任意其他程序化路由尚未统一保护。

## 桌面关闭目标与未完成交付

- 设置关闭守卫使用独立的 `settings` 状态，提供返回应用／放弃修改并关闭，不沿用报告的保存并关闭语义。关闭快照单次消费，修改、取消、重新注册或卸载使旧决定失效。
- 保存／上传优先保留窗口；状态读取失败、放弃失败或中途新增草稿不能批准关闭。与现有主进程流程一起合并重叠关闭／退出请求，不提前停止服务。
- 放弃后走普通窗口关闭，保留渲染器最终 `beforeunload` 否决；不能直接销毁窗口。报告原有关闭语义保持独立。
- 此协议需要前端、预加载和主进程配套交付。旧隔离 Electron 检查只使用过模拟原生选择，不是已安装程序、实际系统提示框或完整安装包的验收。
- 尚需归并页面与原生关闭链路，并验证真实配置写入和安装包。系统强退、断电、跨刷新／设备凭证恢复、原生输入法、Safari／Firefox 和完整读屏不由现有预览证明。
