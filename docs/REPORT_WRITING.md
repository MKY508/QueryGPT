# 报告专注写作

交互参考 [Zulip 展开输入](https://zulip.com/help/resize-the-compose-box)。ReportTextEditor 是报告当前草稿的视图，不维护第二份正文、独立历史或自动保存。

- 桌面窗口 1120px、标题栏 60px，正文与预览固定双列；按钮复用 Button，Tab 边界复用 containModalTab。保留报告专用原生窗口而不使用隔离快捷键的 TaskDialog；快捷键归属见下文。
- useReportWritingMode 拥有模式、组合输入、最后编辑字段与选区／滚动记录。离开纯预览时只对仍相同的文字恢复偏移；内容改变不应用旧选区。语言与正式编号更新不重建窗口，真正的报告／页面／区块目标失效由调用方关闭。
- 标题与正文交回既有报告更新函数，保留依据、来源及其他元数据；预览直接使用 ReportBlockCard。仅编辑纯文本，不把用户内容作为 HTML 或 Markdown 执行。reportBlockText 读取自己的有效文本字段，保留空串、换行与标点。
- 返回只结束写作视图，保留报告草稿，不触发保存；保存状态、失败及草稿恢复警告由报告会话提供。首次保存的身份重连、保存中继续输入、冲突处理和持久化仍属于报告编辑器，不能由窗口测试证明。

验证：工作区 3 个既有定向用例覆盖原文编辑／预览、位置恢复和组合输入；暂存源码 3 个定向用例覆盖位置／组合输入、编号更新保留窗口与快捷键传播，26 个依赖模块类型检查及 ESLint 通过。隔离 Chrome 中英文 1180px 验证几何、反向选区、对照、报告保存快捷键回调及关闭焦点，无服务请求。未验证真实保存、全量构建或安装包。

## 快捷键归属

`useReportKeyboard` 统一保存、打印与报告撤销／重做，复用 `hasModalDialog` 判定真正模态，不再维护移动抽屉豁免。按 [WAI 模态规则](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)，其他任务窗口打开时不得操作底层报告；专注写作窗口内仍操作同一报告，窗口外不接收报告动作。普通侧栏和非模态原生面板不阻断文档。

`report-editor-fields` 独立描述参与文档历史的字段，历史算法不再依赖 DOM。搜索、选择框与富文本保留原生撤销。IME、重复键和已处理事件不重复发出动作；模态期间拦截浏览器保存／打印，但不发出报告请求。

快捷键验证：6 条归属用例、2 条工作区写作／查找用例、限定 ESLint 与全前端类型检查通过。Chrome 中英文 1180×700 验证写作撤销／重做、原生叠加模态阻止底层保存及关闭后恢复保存。每种语言仅一次 PATCH，均拦截为模拟冲突；没有真实服务写入，报告会话整体归并仍待完成。
