# Report action menus

`ReportActionMenu` owns toolbar and block-card menu positioning, keyboard navigation, outside dismissal and trigger-focus restoration. Its shared Button supports text or an icon; card menus align to the trailing edge and flip upward near the window bottom. Destructive actions use the shared destructive color. Actions own their business operations; the menu closes and restores focus before invoking an action.

The interaction follows the [WAI-ARIA menu-button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/). Arrow keys skip disabled items; Escape and Tab return to the toolbar. Composition events and key code 229 do not open, navigate or dismiss the menu. The parent supplies a stable `onOpenChange` callback so content updates do not reset menu focus.

The report workspace holds one menu identity (`add`, `more`, `export`, or `null`), not three independent flags. A menu's dismissal clears only its own identity; closing an earlier menu cannot dismiss its replacement. Navigation, reading mode and task entry clear the menu. The investigation picker likewise uses its selected mode or `null` as its sole opening state.

`ReportMoveBlockDialog` owns initial search focus and captures the opening trigger before opening the native dialog; the frame's close button must not autofocus first. Shared focus traversal follows the document-order TreeWalker approach used by [Radix FocusScope](https://github.com/radix-ui/primitives/blob/main/packages/react/focus-scope/src/focus-scope.tsx). Hidden, inert and excluded controls are skipped. Tab wraps within the dialog; closing returns to its opener, following the [APG modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).

Workspace/card integration remains part of the uncommitted refactor. Six focused checks cover menu keys, dynamic focus ordering, hidden controls, duplicate blocks, save-before-refresh, and moving a block through save/undo/redo. Actual Chrome checks at 1180×600 in both languages cover upward menu positioning, initial search focus, both Tab boundaries and Escape return. Browser reads and integration persistence are mocked; these checks do not establish real export or persistence availability.
