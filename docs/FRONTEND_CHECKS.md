# Frontend integration checks

Run `node_modules/.bin/tsc --noEmit --incremental false` from `apps/web` when validating the complete frontend, including tests. Scoped dependency checks are useful during changes but do not establish this gate. Do not remove tests from the TypeScript configuration to make the gate pass.

Testing Library role queries accept `name`, not Playwright's `exact` option. String names already use exact matching; preserve regular expressions and predicates. See the [official ByRole API](https://testing-library.com/docs/queries/byrole/). The refactor removes 99 unsupported options from 22 files without changing names or assertions. Observer mocks explicitly declare callable signatures; heterogeneous tabular fixtures use record types rather than inferred unions involving inherited `toString`.

The complete frontend type gate now passes, including tests. Query mocks inspect unknown parameters before access; preflight and standing-analysis fixtures include their real required fields, and an in-flight standing analysis is a claim object rather than a boolean. The stale-report fixture explicitly sets both page versions. Seven selected history, semantic-selection, report-reload, source-directory, activity and localized-preflight checks pass. This remains a worktree-level result, not proof that the entire refactor is committed or release-ready. No full build or full test suite was run.

`PreflightInputError` emits string facts and integer line numbers. The API `PreflightIssue` response model must retain `presentation_code` and `presentation_facts`; the frontend type mirrors that string/number contract. Previously the response model discarded those fields and the frontend type wrongly excluded numbers. Two direct Python serialization checks pass through `PreflightReportResponse`, preserving numeric line facts and omitting absent presentation fields. The local API environment lacks pytest, so these functions were invoked directly without installing dependencies; existing `schema` field-shadowing warnings remain. Live API transport is not covered.
