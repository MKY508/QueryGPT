# 桌面界面合同

当前目标是只保留桌面产品，并统一所有前端的视觉、控件和交互。中英文切换继续保留；“统一 UI 语言”不是删除翻译。旧文档中的手机抽屉、触屏尺寸和窄屏全屏编辑不再是实现要求。

## 统一规则

- 设计最小宽度 1180px，导航 248px，标题栏 60px。桌面窗口内可以调整内容宽度，不因窗口变窄切换到手机菜单或全屏编辑器。
- 工作台和设置使用同一层次：低对比导航背景、独立的正文面板、单一强调色。浅色与深色都由主题变量决定，设置页不再固定深蓝侧栏。
- 几何值只在 `desktop-tokens.css` 定义：控件 6px、菜单 8px、内容面板 12px。Tailwind 的圆角名称映射到这些语义；胶囊只用于标记，不作为所有按钮的默认形状。
- 普通导航是 `aside`，配置编辑是命名 `section`，不是 dialog。明确折叠导航保留 DOM、草稿和查询，并在必要时返回触发按钮；不锁住整个工作区的 Tab。
- 确认放弃、删除及明确打开的任务窗口仍可使用真正的模态。IME Escape、已处理事件和别的模态不能误触发底层面板关闭。
- 搜索复用 `SearchField`，按钮复用 `Button`。搜索统一清除、组合输入和 Escape 行为；列表可通过 `aria-controls` 关联被过滤内容，不再另写一套搜索输入。
- 页面入口、列表操作和编辑动作使用同一控件层；避免页面各自维护不同颜色、直角按钮和触控尺寸。表单的提交、错误及草稿合同不因外观修改而改变。

## 实现与剩余范围

基础按钮、搜索、桌面导航、配置编辑面板及圆角变量已收拢。当前工作区的工作台和设置页已移除移动分支，设置的目录与 420px 编辑区固定并排；这些页面仍与之前的大批未归并改动交织，不能把局部组件提交视为全部页面完成。

关于页已改为固定桌面布局：统一标题栏、产品与版本双栏、三列项目链接。版本检查的行为改动独立于视觉提交，仍在工作区中待归并。

项目理解的当前工作区已收敛为 200px 范围目录、单一表格和 320px 详情区；删除重复手机卡片、来源下拉和详情宽度监听。共享搜索、按钮与页面外框已接入。详情组件独立提交；完整页面仍与历史、选择和保存恢复的既有改动交织，待继续归并。

数据来源目录已改为固定 280px 列表与详情并排，删除隐藏列表的容器断点和尺寸监听。样式由 `SourceDirectory.module.css` 单独维护，搜索与状态筛选复用共享控件；来源版本往返和实际准备操作保持原有语义。目录及其状态、版本解析独立归并，外围数据工作区仍待整体整理。

展开数据表已收拢为独立模块：表格、搜索、筛选和分页始终保留，记录详情固定在右侧 360px；删除手机详情替换表格的分支和焦点尺寸监听。列设置、排序、筛选及记录选择不再使用手机断点。表格模型、精确数值、CSV 与剪贴板逻辑随模块归并，复用已有 Decimal 和 Papa Parse。来源预览与整理编辑器仍在工作区待归并，不能将独立数据窗口视为所有入口完成。

后续必须覆盖：

1. 归并工作台与设置的完整页面依赖、草稿会话及离开链路。
2. 数据浏览、理解与整理页面的桌面布局，移除各自残留的移动切换和重复控件。
3. 报告阅读、报告编辑、历史、项目与关于页面，统一标题栏、工具栏、字段、菜单、空态和错误态。
4. 校准全部弹窗及表格的圆角、间距、密度和键盘行为，移除硬编码尺寸与过时手机样式。
5. 检查桌面窗口约束、真实安装包与全站导航；局部源码和预览通过不代表已安装应用交付。

## 参考与验证

参考 Twenty 的 [NavigationDrawer 源码](https://github.com/twentyhq/twenty/blob/main/packages/twenty-front/src/modules/ui/navigation/navigation-drawer/components/NavigationDrawer.tsx)中导航、内容和主题变量的职责划分。只采用桌面分工，不采用其手机分支或依赖；没有复制第三方源码。

数据来源采用 [PatternFly Drawer](https://www.patternfly.org/components/drawer/) 的 inline 主从内容分工，不采用覆盖式或断点切换，也不新增依赖。

数据目录的暂存源码检查覆盖键盘浏览、筛选期间保留详情、来源删除、语言切换和编辑 Escape。Chrome 在 1200px、1440px 验证列表始终可见、双栏布局、12px 外框且无页面横向溢出；[当前工作区预览](images/zh/desktop-ui-sources.png)使用虚构来源，不作为真实文件准备或后端写入的验证。

数据窗口核心检查独立于报告和聊天入口：暂存源码的 8 个定向用例覆盖桌面面板共存、列重排、多列排序、筛选、IME Escape、剪贴板竞态、完整快照查询及重新打开；26 个模块的限定类型检查无错误。Chrome 使用虚构来源验证 1200px、1440px 下表格与 360px 详情并排，1200px 下的[列菜单](images/zh/desktop-ui-data-columns.png)和[筛选面板](images/zh/desktop-ui-data-filters.png)无溢出，菜单圆角为 8px，无控制台错误及写请求。来源预览与整理窗口另有 7 个工作区用例；尚未验证真实文件、完整构建或安装包。检查使用当前已安装依赖，不代表旧版本依赖的全新安装验证。

定向入口为 `settings-editor`、`analysis-workbench`、`workbench-pane-focus`、`settings-page` 和现有 `SearchField` 检查。浏览器使用隔离预览，只读虚构配置，检查桌面导航折叠、设置栏目往返、编辑保留、并排边界及主题。不进行手机验收，不调用真实模型或写入配置。
