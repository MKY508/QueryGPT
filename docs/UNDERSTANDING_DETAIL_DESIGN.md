# 项目理解

桌面布局与尚未归并的范围见 [桌面界面合同](DESKTOP_UI.md)。本文件只维护已归并模块的交互约束。

## 定义编辑窗口

SemanticDefinitionEditor 复用 TaskDialog，拥有原生窗口、表单滚动、固定保存操作栏与焦点返回；草稿、版本校验、保存请求及放弃确认仍由项目理解会话持有。主页面接线目前在工作区，尚未整体提交。

- Escape 只请求关闭，不先关闭原生窗口；草稿可由调用方继续保留。输入法 Escape 不触发退出；写入同步锁或保存核对状态阻止程序化重复提交。
- 编辑／语言更新保留窗口与原字段节点。明确载入保存内容由调用方聚焦名称，不为字段值变化关闭重开窗口。
- FieldControl.module.css 从既有设置表单提取。设置与定义字段共享圆角、焦点、无效状态和禁用样式；不新增输入协议或表单状态库。

## 整理项目理解

窗口结构参考 [PatternFly 任务模态](https://www.patternfly.org/components/modal/design-guidelines/)，复用 TaskDialog 的原生模态、键盘边界、1120px 宽度与 60px 标题栏。选择方式及表清单固定桌面双列，控件复用 Button。

- SemanticGovernanceDialog 只在打开时创建按项目隔离的会话；重开／换项目清除选择与请求结果。提交使用同步锁，期间关闭、取消、Escape 和重复提交均不可用；旧项目迟到响应不触发新项目回调。不能撤回服务端已收到的任务。
- semantic-governance-sources 独立维护业务名称、目录与已分析表的合并。同名跨 schema 的表仍按完整身份区分；此次提取不改变既有目录合并规则。
- 打开窗口仍沿用已有 relation-index 刷新，目录失败保留当前可用表；该刷新不是模型整理。文件与数据库整理只由明确开始触发；部分成功后只保留失败来源，避免重复启动已成功部分。
- 会话读取打开时的来源快照，目录刷新在本窗口合并；不是持续来源同步、跨窗口任务锁或持久化队列。真实模型调用和数据库整理尚未联调。

## 保存冲突与结果核对

交互参考 [VS Code 冲突选择](https://code.visualstudio.com/docs/configure/settings-sync#conflicts)、[React 身份隔离会话](https://react.dev/learn/preserving-and-resetting-state#resetting-state-with-a-key)及 [PatternFly 内容卡片](https://www.patternfly.org/components/card/design-guidelines/)，沿用现有依赖，不自动覆盖或合并。

- 保存结果核对项目、条目／键、新版本及提交的名称、说明、类型和采用状态；不明确结果保留表单。新建沿用首次提交的目标键，不随名称编辑另建目标。返回校验不是全部派生字段的等价证明。
- SemanticSaveRecovery 按项目、定义键／身份及预期版本重建会话；读取为互斥状态，同步锁阻止重复读取。目标改变／卸载取消原请求，迟到响应不能污染新目标。语言与草稿文字改变保留当前比较；读取完成仅在用户仍停留于原操作时交接焦点。
- 仅明确点击才读取：已有定义按项目／ID，新建按原始键精确 lookup。当前已保存与我的输入固定双栏，卡片 12px、动作复用 Button；读取不修改表单，不表示此前保存已成功。
- 未变版本或未找到创建目标才允许返回编辑，按钮本身不写入；未找到不保证旧写入已终止。载入需二次确认替换整个表单；取消保留草稿，确认交回读取的完整定义，编辑器更新基线／版本并聚焦名称。移除、错归属与失败结果不可载入。
- 仅比较业务名称与说明，不提供字段级差异、三方合并、强制覆盖、持久回执或跨重启恢复。真实保存／lookup 接口及全页面行为仍需联调；历史模拟测试不能证明已部署。

当前桌面验证与截图见 [桌面界面合同](DESKTOP_UI.md)。
